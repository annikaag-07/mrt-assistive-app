🚇 MRT Sense

📌 Project Overview

MRT Sense is a multi-modal accessibility support application designed to enhance MRT navigation for individuals with visual and hearing impairments.
Public transport systems often rely on a single sensory channel — either audio announcements or visual signages. In crowded and noisy stations, this may not always be reliable.

MRT Sense introduces a layered feedback system that combines:

📳 Haptic feedback (vibration patterns)
🔊 Audio guidance (text-to-speech prompts)
👁️ High-contrast visual cues

Rather than replacing existing MRT systems, the application complements them by reinforcing navigation signals across multiple modes.

🎯 Key Features

🚆 Journey Simulation
Simulates train arrival alerts, stop announcements, and exit reminders for demonstration and testing.

📍 Platform Alignment Mode
Provides vibration cues to guide users toward safer boarding positions.

🧭 Guided Exit Mode
Offers step-based directional guidance using audio and visual reinforcement.

🚨 SOS Hold Feature
A long-press emergency button that activates repeated feedback signals.

⚙️ Accessibility Profile
Allows users to customise preferred feedback types and settings.

🛠️ Setup Instructions

📋 Prerequisites
• Node.js
• Expo CLI
• Expo Go (mobile device) or an emulator

💻 Installation Steps

Clone the repository
git clone <repository-link>
Navigate into the project directory
cd mrt-sense

Install dependencies
npm install
Start the development server
npx expo start

Scan the QR code using Expo Go or run the app on an emulator.

▶️ Usage

Launch the application.
Select a mode (Simulation, Alignment, or Exit).
Configure accessibility preferences if required.
Follow the vibration, audio, and visual cues provided.
Hold the SOS button when emergency feedback is required.

💡 Design Principle
MRT Sense focuses on reinforcing accessibility across multiple sensory channels, making navigation clearer and more reliable in real-world MRT environments.
